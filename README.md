# 💰 Income and Expense Tracker Dashboard

A sleek, production-grade, and interactive **Income & Expense Tracker Dashboard** built using vanilla modern web technologies. This project features high-fidelity glassmorphic and flat design elements, multi-metric financial KPI cards, and dynamic data visualization utilizing **Chart.js**.

---

## ✨ Features

* 📊 **Dynamic Data Visualization:** Real-time updates on modern Doughnut and Bar charts for spending distribution and monthly overviews.
* 📈 **Financial KPI Cards:** Tracks Total Balance, Monthly Income, Monthly Expenses, and Savings Rate instantly.
* 💾 **Persistent LocalStorage:** Entries stay securely saved inside your browser's local memory—no database setup required.
* 📱 **Responsive Grid Layout:** Beautifully adapts to desktops, tablets, and mobile browser viewports.
* 🛍️ **Smart Form Validation:** A clean animated modal window to seamlessly input real-time transactions.

---

## 🛠️ Tech Stack Used

* **HTML5:** Structure, Semantic layouts, and Dashboard UI architecture.
* **CSS3:** Custom layout styles, CSS variables, Grid/Flexbox architecture, and micro-interactions.
* **JavaScript (ES6+):** State management engine, LocalStorage operations, UI data binding, and events.
* **Chart.js:** Engine for rendering rich data-driven analytics charts.
* **FontAwesome:** Vector icons for modern navigation context.
